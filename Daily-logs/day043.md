# Day 43 : SW/LW/BEQ Testing, Makefile Update and Feature Branch Merged

## Makefile updated 
test_cpu_integration was added with data_mem.sv in the compile command and test_alu and test_cpu_integration were grouped to test_cpu and added to main test rule.

## sync_ram vs data_mem
Our sync_ram had synchronous reads which was breaking single cycle CPU integration as instructions like lw would need 2 cycles because of that. So we created data_mem with combinational reads and synchronous writes which easily fit in our single cycle CPU.

## SW/LW/BEQ Test Program
8 instructions were added in program.hex to test different instructions including sw/lw/beq. The 8 instructions were correctly working which verified the correct working of our CPU.
- Address 0x00: ADDI x1, x0, 5
- Address 0x04: ADDI x2, x0, 3
- Address 0x08: ADD x3, x1, x2
- Address 0x0C: ADDI x4, x0, 10
- Address 0x10: SW x4, 4(x0)
- Address 0x14: LW x5, 4(x0)
- Address 0x18: BEQ x4, x5, +8
- Address 0x1C: ADDI x4, x0, 7
- Address 0x20: BEQ lands here

## BEQ Verification fix
tick(7) was insufficient to prove branch taken because after 7th edge the branch would have been taken but without the next tick we wouldn't know if it skipped the next instruction to take the branch so to give the next instruction a chance to execute we increased the delay to tick(8) to actually see if the branch worked.
