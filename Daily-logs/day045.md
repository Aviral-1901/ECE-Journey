# Day 45 : Phase 1 Gate

##  D latch vs D flipflop
In latch output follows the input while enable is high(level-sensitive), flip-flop output is updated only at clock edge(edge-sensitive).

## Moore vs Mealy FSM
Moore FSM output depends only on state whereas Mealy FSM output depends on state as well as the input. Traffic light is a moore machine.

## Latch Inference
Latch is inferred incase of incomplete signal assignments in always_comb. It is prevented by using defaults at the start of the block.

## 2's complement
11110000 = -128+64+32+16 = -16.   Here the MSB is always sign bit and 1 here means negative. And the rest of the calculation is done normally as like with other binary numbers.

## BEQ vs BLT
BEQ uses zero flag for working because it compares two registers by subtracting and if the values are equal then zero flag is set which is looked to know for branch. BLT needs signed comparison output which our current CPU doesn't support.

## Branch and Zero Flag
If only zero flag was used for PC_muxselect signal then any operation could have set the flag leading to unwanted branching. So we need Branch & Zero flag so that branching occurs when zero flag is set and it is a branch instruction at the same time.
