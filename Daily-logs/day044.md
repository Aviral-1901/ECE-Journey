## D latch vs D flipflop
In latch output follows the input while enable is high(level-sensitive), flip-flop output is updated only at clock edge(edge-sensitive).

## Critical Path
It is the longest path between two sequential elements in the circuit. PC → imem → control_unit/imm_gen (decode) → register_file (read) → ALU → register_file (write). LW has longest path in our CPU with this path PC → imem → control_unit/imm_gen (decode) → register_file (read) → ALU → data_mem (read) → register_file (write)

## x0 hardwiring
x0 is always hardwired to give 0. We had write_guard for this write_address!=0 during write operation and we had if read_address=0 then it always gives value 0.

## Fixed register positions
Hardware extracts rs1/rs2 registers from the instructions unconditinally before knowing instruction type. Immediates are scattered because reassembling immediate is cheaper and is a acceptable tradeoff.
