## CMOS NAND
To make NAND gate we need PMOS transistors in parallel at top and NMOS transistors in series at bottom. The inputs A and B are given to the gate terminal of these transistors. PMOS turns ON when input=0 and OFF when input=1 and NMOS turns ON when input=1 and OFF when input=0. NAND gate gives output 0 when both inputs are 1 so when both inputs are 1 the top PMOS transistors are OFF and bottom NMOS transistors are ON so output gets connnected to ground through NMOS transistors path giving output 0.

## Overflow detection in Ripple Carry Adder
In ripple carry adder overflow occurs in 2 cases. First case when Cin into MSB adder is 1 and Cout from that adder is 0. Next case when Cin into MSB adder is 0 and Cout from that adder is 1. So looking at the cases we can clearly see overflow occurs when Cin into MSB adder and Cout from that adder are different which can be represented by using XOR operation. For 4 bit number we can show it with this expression : overflow = Cin3 XOR Cout3

## Mealy FSM '1011'
We need 4 states : s0, s1, s2 and s3 for this sequence detector. On s0 getting 1 gets us to s1 and getting 0 stays at s0. On s1 getting 0 gets us to s2 and getting 1 stays at s1. On s2 getting 1 gets us to s3 and getting 0 gets to s0. On s3 getting 1 gets us to s1 for starting a new sequence with output=1 and getting 0 gets to s2 because the longest prefix which can be used is 10 which is in s2.
