# Day 55 : cocotb testbench for register file

## Register file model
Register file model was implemented in Python using [0]+[None]*31 to simulate the register behaviour at the start and register-x0 always gives 0 and None marks the registers where no value was written (the hardware shows x on simulation and int() on x raises ValueError).

## Clock in cocotb
Clock(dut.clk, 10, unit='ns') runs on its own in the background, await RisingEdge(dut.clk) is used for waiting for the rising edge of the clock.

## Timing Rule
A write lands at clock edge, a read right at the edge sees old values. So wait 1ns after the edge to let the values settle and read the new correct values. After changing any input of combinational logic (like the read_address), we again wait for 1ns before reading to let the inputs settle as well.

## Four Tests
Four scenarios (write then read, write to x0 ignored, two registers read on both ports, write enable off) were each tested by breaking register_file.sv on purpose. Removing only the write guard on x0 is undetectable from the pins because the read path forces 0.
