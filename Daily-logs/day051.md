## cocotb fundamentals
We use cocotb in python to make module testbenches and testing more effective. It offers more functionalities and tools to test which manual .sv testbenches lack. We use @cocotb.test() decorator to mark a function as a cocotb test and runs the test when the simulation starts. dut(Device Under Test)parameter lets python interact with verilog design by giving Python code the access to the signals of the module. async def is used to make the function as test function and we use dut.signal_name.value to read and write to a signal. We used Timer for combinational logic settling time.

## tb/cpu/Makefile
This is a cocotb Makefile that requires specific information like the path to the RTL and the name of the top-level module. When writing the testbench file using cocotb it is a convention to name the file test_module.py. In the Makefile we set the MODULE variable to match the Python filename (without the .py extension) so the test runner knows where to look.
