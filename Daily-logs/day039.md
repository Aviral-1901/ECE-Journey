# Day 39 : PC Logic, Branch Mux, and Control Unit Truth Table

## PC Sequencing
PC increments by 4 for normal instructions and PC + offset for taken branches so offset is relative to PC not a data register.

## Branch MUX
Another mux added to the things we discussed from yesterday. It is used to select what is added into PC. If input 0 then PC increments by 4 and if input 1 then PC is added with the offset value from the instruction. Its output is the next address for the instruction and The select signal for this is the zero flag AND branchsignal. Branch_signal AND zero_flag acts as select signal because with zero flag only it may work when any other operation makes zeroflag=1 so to prevent that we AND it with branch signal so it only works when it is branch signal and zero flag is high. BEQ x1, x2, offset - It compares the registers x1 and x2 and if they are equal then it looks at zero flag because the comparison actually happens by subtracting the value of those two registers and based on that branching occurs.


## Control Unit
It generates all the control signals like the memWrite, RegWrite, ALUsrc, MemToReg, branch. It takes only the opcode as input and generates the control signals combinationally.

## Control Unit Truth Table

| Instruction | RegWrite | MemWrite | MemToReg | ALUSrc | Branch |
|-------------|:--------:|:--------:|:--------:|:------:|:------:|
| R-type      |    1     |    0     |    0     |    0   |    0   |
| LW          |    1     |    0     |    1     |    1   |    0   |
| SW          |    0     |    1     |    X     |    1   |    0   |
| BEQ         |    0     |    0     |    X     |    0   |    1   |


## Don't Care Condition
MemToReg is x whenever the regWrite=0. When register file write is disabled, write-data has no effect on writing to register.

## RegWrite vs PC update
RegWrite signal only controls the register file x0-x31 registers. PC is also a kind of register but RegWrite do not affect that and PC has its own update logic.
