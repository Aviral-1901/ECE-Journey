# Day 49 : JAL and JALR Implementation Complete

## JAL
jal rd, immediate. CPU saves PC+4 to rd register and jumps to PC+immediate. JAL is a j-type instruction with 20 bits of immediate which can be used to jump ±1MB range.

## JALR
jalr rd, immediate(rs1). CPU saves PC+4 address to rd and rd can be any register but we have seen x0 as rd till now. x0 as return address discards the return address. After saving the address it jumps to rs1+immediate. It is an I-type instruction and has an immediate in the instruction so to select immediate as ALU's B input we set ALUSrc=1.

## Link Register Convention
x1 (ra) holds the return address by convention and x0 as rd discards the return address.

## New Control Signals : Jump and Jalr
jump and jalr signals added to control unit. They are used to distinguish JAL from JALR.

## MemToReg extended to 2-bit
MemToReg MUX is extended to 2-bit. For input 00=ALU_Result, 01=RAM_Data, 10=PC+4 (return address). It is handled using chained ternary operator in cpu.sv

## PC MUX extended to 3-way
Now PC MUX is able to select 3 ways of updating PC. For jalr: PC=ALU_Result,  for jump/branch : PC=PC+imm and for normal execution PC=PC+4.

## J-type Immediate in imm_gen.sv
imm_gen is updated to handle j-type immediate. It extracts the required bits from the instruction based on the opcode and assembles them extending the MSB to make it 32 bits which is required for ALU.
