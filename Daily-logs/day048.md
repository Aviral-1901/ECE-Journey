# Day 48 : Byte/HalfWord Memory Access

## Word vs byte addressing
Each 32-bit RAM slot contains 4 bytes. Previously our data_mem.sv would only work with word addressing, we couldn't extract a byte of data from the 32-bit RAM. Now with byte addressing the byte address is split into a word index (address >> 2) and a byte offset (address[1:0]).

## Byte Extraction
We shift the raw word to right by (byte_offset * 8), take bottom bits and extend it as per signed or unsigned operation to get the full 32 bits of data which is necessary for CPU to operate on and this works for bytes and halfwords.

## Sign vs Zero Extension
LB/LH operations use sign extension with replicating MSB sign whereas LBU/LHU zero extend the data to make it full 32-bit data useful for CPU operation. funct3 value is used to distinguish between these.
