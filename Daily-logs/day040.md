# Day 40 : CPU wire list, Immediate Generator and Control Unit

## Immeditate_generator
We create imm_gen.sv which is used for extracting the immediate value from the instruction and sign extending it to make 32bits. It looks for opcode and based on that it selects the correct bit positions for different instructions(I/S/B) and makes the full 32bits immediate value.

## Control Unit
We made a control unit that is commited in the feature branch for now which takes in opcode as an input and produces required control signals. For now it will be generating 5 control signals for different operations.

## PC confusion
Instructions are stored in memory and PC holds the address of those instructions. So we will manually create an array of size 256 each 32 bits wide to simulate the instructions being in memory. But doing this the next instruction would be in increment of 1 step of array and not in increment of 4 which our PC uses. So we divide the pc value by 4 to make this work which can be done by doing pc >> 2 and which in simpler form is just doing pc[9:2].

## CPU wire list
These are the cpu internal wires fixed for today.
- logic [31:0] pc; //current pc value
- logic [31:0] instruction;
- logic [6:0] opcode;
- logic [4:0] rs1, rs2, rd;
- rs1 = instruction[19:15];
- rs2 = instruction[24:20];
- rd  = instruction[11:7];
- logic [31:0] imm;
- logic zero_flag;
- logic RegWrite, MemWrite, ALUSrc, MemToReg, branch;
- logic [31:0] read_data1, read_data2;
- logic [31:0] alu_result;
- logic [31:0] ram_read_data;
- logic [31:0] ALUSrc_muxout, MemToReg_muxout, PC_muxout;
