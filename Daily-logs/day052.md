# Day 52 : Complete cocotb verification for all 10 operations

## Reusable test template
We made a reusable function test_alu_op which receives different parameters so all the operations can use this template and eliminates per operation duplication.

## Reference models derived
Reference models for all the operations (expected_result) was derived. Shifts required b%32 for wraparound as for shifting we only look at the lower 5 bits which is represented by b%32.<br>
In any operation if the result can exceed 32 bits or can be negative, we used outer % (2**32). All 10 opoerations were checked and every one of them passed. (In left shifting, Python can shift and store the resulting number as 33+ bits because it has infinite precision. This is not how our 32-bit hardware works, so the 32-bit wraparound was strictly necessary to truncate the extra bits)
