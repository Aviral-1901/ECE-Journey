# Day 42 : First End to End CPU Simulation Passing

## cpu_tb.sv
Hierarchical references (dut.reg_file.registers[N]) to check internal register values without needing to route them to output ports. This allows us to easily inspect internal signal states during verification.

## program.hex
3 instructions were added in hex inside program.hex. ADDI x1,x0,5 / ADDI x2,x0,3 / ADD x3,x1,x2 were added as hex instructions inside program.hex file.

## Icarus syntax fix
Icarus Verilog doesn't support complex signal slicing and concatenation directly inside an always_comb block. So we have to create a signal outside the always block, assign it the sliced value outside and use it inside the always block. It was fixed in imm_gen.sv and control_unit.sv

## I-Type Arithmetic 
control_unit.sv and imm_gen.sv were updated to handle I-type arithmetic operations like ADDI, ANDI and other I-type operations.

## Simulation Passing
After the simulation all the registers values were as expected. x1=5, x2=3 and x3=8 all were correct. Instruction fetch from instruction memory (program.hex), decoding, ALU calculation and writeback were confirmed to work well.
