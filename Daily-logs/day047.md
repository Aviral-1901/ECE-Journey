## SRA vs SRL 
SRA shifts the number to right filling the empty positions with MSB values which is important for signed numbers. SRL shifts the number to right filling the empty position with 0. SRA is implemented using : $signed(a) >>> shift_amt.

## SLTU vs SLT
SLTU treats numbers as unsigned while SLT treats numbers as signed. The bits are same but the interpretation is different. 0xFFFFFFFF is -1 signed but 4294967295 unsigned. For SLT we need $signed(a) < $signed(b) and for SLTU it only needs a < b.

## Control Unit Updated
Control Unit and ALU is updated to handle SAR and SLTU operations as well. SRA maps to {funct7[6]=1, funct3=101} = 4'b1101; SLTU maps to {funct7[6]=0, funct3=011} = 4'b0011.
