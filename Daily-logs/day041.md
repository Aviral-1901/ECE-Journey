## Instruction fetch
Our imem has 256 slots each 32 bits wide which simulates our instruction memory. So instructions are placed in each index step and not by +4 by which our PC updates. So to make PC work we only take the pc value starting from bit2 to bit9 because our RAM needs 8 bit address to select from its 256 depths. So imem[pc[9:2]] is used and for RAM, ALU generates the address which is 32 bits but we only require 8 bits so we again do alu_result[9:2] for selecting RAM.

## sync_ram instantiation
WIDTH=32 and DEPTH=256 for our RAM. These parameters override the parameters that were in sync_ram.sv. Here the address is selected using alu_result[9:2].
